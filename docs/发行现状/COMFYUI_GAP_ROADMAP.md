# 与 ComfyUI 的差距 · 通往 1.0.0 的路线图

本项目 `src/deployment/workflow_ui.py` 提供了一个零第三方依赖的 ComfyUI 风格节点图工作流编辑器。
本文档记录它相对真实 [ComfyUI](https://github.com/Comfy-Org/ComfyUI) 的剩余差距。

> **里程碑门槛**：下面的「待补齐」项全部完成并通过验收后，即可进入正式版 **1.0.0**。
> 当前版本：**0.18.1（更好的存档 · 预制存档走 ComfyUI 规范）**。

---

## 〇、已完成（0.18.1）✅

| 能力 | 说明 |
|---|---|
| 预制存档（蓝图） | `src/blueprint.py` 把表层工作流 + 模型存档打包为 `.blueprint.zip`（ZIP_STORED 不压缩），供分发/复现 |
| ComfyUI 规范工作流 | 蓝图内 `workflow.json` 严格遵循 ComfyUI v1.0 格式（`version/config/state/groups/nodes/links`、节点 `pos/size/flags/order/mode/inputs/outputs/properties/widgets_values`、连线 `[id,origin_id,origin_slot,target_id,target_slot,type]` 元组） |
| 双向转换 | `to_comfy`（内部图→ComfyUI）/ `from_comfy`（ComfyUI→内部图），round-trip 一致 |
| CLI 子命令 | `dformer blueprint save/load/list`（save=打包、load=解包还原+模型落盘、list=读 manifest 不落地） |

## 二、已知问题（Known Issues）

> 以下为 0.17.0 及更早版本记录的已知问题，**已于 0.18.0 全部解决** ✅。

1. ✅ **拖拽偶发瞬移 / 状态残留**（已解决）：修复节点拖拽锚点——抓取偏移仅按下瞬间锚定一次，每帧重算抓取节点目标并让其余选中节点保持相对位差，节点精确跟随鼠标、不再漂移/只朝右下移动；新增 `finalizeDrag()` 在鼠标窗口外松开或按键丢失时清理残留态，`mousemove` 检测 `buttons===0` 立即终结，拖拽期间画布 `user-select:none` 不再误选文本。
2. ✅ **框选无状态栏反馈**（已解决）：状态栏在框选/多选/选中连线时实时显示「选中 N 节点 · M 边」，如 `选中 3 节点 (12 节点 · 15 边)`。
3. ✅ **缺少"点选—操作"闭环**（已解决）：连线加宽透明命中路径(`edge-hit`)，点选细线也能选中；选中节点/线段后画布上弹出浮动操作条（多选时在选区质心显示「已选中 N 个对象」+ 转为组/删除；单选节点：重命名/重复/旁通/禁用/删除；连线：断开），即点即操作，且跟随节点拖拽移动。
4. ✅ **输入与分组能力缺失**（已解决）：输入节点新增「自然语言/消息/数据」文本输入 + 「📂 载入文件到 data」（读取 txt/json/csv/md 等，JSON 自动解析）；选区组新增**着色**色板（6 色），与既有折叠/命名组合成完整区域分组。

## 三、待补齐 ➡ 补齐后即 1.0.0 ⬜

按推荐实现顺序分组。

### A. 服务端执行模型（最重要）
- [ ] **真实服务端任务队列**：执行由服务端管理，返回全局 `task_id`，可查询状态/结果/历史（当前仅前端队列，无服务端持久任务）。
- [ ] **中断/取消(Interrupt)**：提供 `/interrupt` 与全局 Interrupt 按钮，终止当前任务；当前仅前端 abort 标记。
- [ ] **输出历史查看器**：每个任务的输出(文本/JSON/数字/图像)存入服务端历史，侧栏可回看并复用前置结果。

### B. 节点库与导入导出
- [ ] **可搜索节点库**：按分类折叠、支持文本过滤、模糊搜索的完整节点调色板（当前只在双击浮层列出，且不分类/不折叠）。
- [ ] **模板/示例图库**：内建若干可一键加载的示例工作流，按用途分类浏览。
- [ ] **ComfyUI 原生 JSON 兼容**：导入/导出与 ComfyUI 一致的 `{nodes, links, groups}` 工作流格式，可直接互换。

### C. 连线与交互细节
- [ ] **边重连**：从边的两端拖出可重新连接到其它端口（当前新建连线，不改边）。
- [ ] **端口类型着色**：按输入类型给端口/边着色，类型不匹配时给出视觉提示。
- [ ] **缩放适配(Home / F)**：一键缩放至适配全部节点、复位视图。

### D. 节点能力
- [ ] **更多 widget 类型**：int/float 步进、combo 多选、checklist、数组/列表编辑器、按钮型 widget(触发动作)。
- [ ] **子流程/折叠宏节点**：把已选节点封装为单个可复用节点。

### E. 多画布与体验
- [ ] **多画布/Tab**：同时打开多张工作流，页签切换，互不干扰。
- [ ] **设置面板与主题**：字号、网格、自动保存、亮/暗主题切换。
- [ ] **状态栏**：显示缩放比例、坐标、节点/边数量等。

### F. 服务端节点注册
- [ ] **动态节点注册**：由服务端按 CuteMamen 插件自动生成节点类别、输入输出 schema 与图标（当前由前端静态 `/api/workflow/models` 枚举）。
- [ ] **自定义节点加载**：像 ComfyUI 的 `custom_nodes` 一样，从插件目录热加载专属节点脚本。
