## Pre0.1（2025-07-16）· 首次公开发行研究归档

首次对外公开发行版，发出即公开。包含从原型到实验验证的全部内容：
完整源代码（核心架构、编解码、智能体、工作流、训练、部署）、全部实验记录
（消融/对照/扩展实验）、训练模型权重（5 组实验检查点 + 最终模型，约 240MB）、
实验报告与可视化图表，以及部署配置（Docker / K8s / 云原生）。

关键组成：

* **核心**：`distributedformer.py` — 脉冲神经网络核心（分形递归、KV 堆、异步事件驱动）
* **编解码**：`spike_codec.py`（标量/文本/图像→脉冲）、`multimodal_codec.py`（多模态融合编解码）
* **智能体**：`base_agent.py` — 5 种脉冲智能体基类（感知/推理/动作/记忆/节律）
* **工作流**：`engine.py` — 脉冲驱动的工作流编排引擎
* **训练**：`train.py` / `trainer.py`（BPTT 兼容）、`data_generator.py`（合成数据集生成器）
* **实验**：消融实验（标准/扩展）、电梯问题实验
* **部署**：`Dockerfile` / `docker-compose.yml` / `k8s/*.yaml` / `redis_kv.py` / `monitoring.py`
* **演示**：`stock_monitor.py` — 智能股票监控端到端演示

技术参数：分形深度 2 · 基础单元 4,096 · 总参数 ~69,888 · 思考层 20 层分形递归 ·
KV 堆容量 256 条目/单元 · 智能体类型 5 种。

### 真实时序异常检测（P0 立项） ✅ 已完成（v0.13.1）

框架声明面向"流式监控 / 异常检测 / 指标巡检"这一持续在线场景，但
v0.6–v0.12 落地的全部基准均为**分类任务**，为补足招牌场景立项本方向
（纯真实、无合成，联动 NAB 官方标注）：

1. **P0 · 真实时序数据集接入**：`OperationalMetricsDataset`
   （`src/data/metrics_time_series.py`），NAB 真实运维指标（real* 系列
   5 个序列）切定长滑动窗口（40 点×stride 20，2720 窗），标签沿用官方告警标注
   （2.6% 异常）；提供 `split_stream(train_ratio)` 时间顺序划分。
2. **P0 · 异常检测评估管线**：复用 `stratified_kfold` + 5 种子 × 5 折，
   窗口级 **ACC / 异常检出率 / 误报率** 纳入 `benchmark-all`。
3. **P1 · 在线持续学习验证**：在线持久输出头 + 非平稳水库在时序流上验证
   漂移/稳定性，对齐 v0.10.2 已缓解的后期漂移。

**结果（R5 异常检测基准）**：窗口级 ACC **48.5%** ± 11.0%（9/25 折超随机
50%），异常**检出率 48.9%** ± 14.8%（多数类全判正常 = 0%），误报 51.5%，
最佳 L2=1e-1、异常权重 10。见
[`anomaly_report.md`](../../src/experiments/anomaly_report.md)。

**结果（R6 时序流在线持续学习）**：时间顺序前后划分（train 951 / val 817，
4 epoch）三配置均**稳定**（drift ≥ −10pct 判定）；默认 **cosine** 后期
零漂移（final=best=97.2%），constant 微小回落 (−1.3%)，freeze@2 −2.7%。见
[`anomaly_stream_stability.md`](../../src/experiments/anomaly_stream_stability.md)。

### 准确率瓶颈解决方案（36% 瓶颈，v0.7.5 诊断结论） ✅ 已完成（v0.8.4）

36% → 75.6%（随机基线 20%，5 种子 × 5 折 CV，种子方差 ±0.8%）。诊断定位
36% 瓶颈在**编码阶段即丢失判别信息**（词袋 TF-IDF 类间/类内距离比 0.68 负可分，
纯静态语法特征达 71.2%）：

1. **P0 · 双模态注入**（v0.8.0）→ **57.6%**
2. **P1 · 结构感知编码**（v0.8.1）→ **57.6% → 61.6%**
3. **P1 · 修端到端权重更新**（v0.8.2）→ 持久输出头 + 感受野投影 → **67.2%**
4. **P2 · 扩真实语料**（v0.8.4）→ 100 → 502 段 → **75.6%**（±0.8%，达 ±2% 目标）
5. **P2 · 5 折交叉验证**（v0.8.3）→ 63.8%，评估不再依赖划分运气
