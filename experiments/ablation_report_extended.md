# DistributedFormer 消融对比实验报告 (扩展版)

- Epochs: 10
- Samples per class: 50
- Seed: 42
- 总训练样本: 200 (4类 × 50)

## 关键发现

- **Baseline (E1)**: depth=1, 无思考监督 → BestValAcc = 30.00%
- **网络规模效应 (E3)**: depth=2 vs depth=1 → 30.00% → 22.50% (Δ = -7.50%)
- **思考监督效应 (E4)**: 开启思考监督 → 30.00% → 30.00% (Δ = 0.00%)
- **v5.2 Full (E5)**: depth=2 + 思考监督 → 30.00% → 22.50% (Δ = -7.50%)

## 效应分解

- 纯网络规模增益 (E3 - E1): -7.50%
- 纯思考监督增益 (E4 - E1): 0.00%
- 联合增益 (E5 - E1): -7.50%
- 协同效应 (Full - 单效应之和): 0.00%

## 观察与讨论

1. **更多数据的效果**: 相比快速版 (3 epochs × 20 samples/类)，扩展版中 depth=1 的 Baseline 从 12.50% 提升到 30.00%，表明更多数据对小网络有帮助。

2. **深度2的反效果**: 但 depth=2 (4,400 单元) 的实验准确率反而下降到 22.50%。这可能表明：
   - 4,400 单元对于 160 训练样本来说容量过大
   - 更深的分形结构需要更长的训练时间或更强的监督信号
   - 当前监督学习机制难以有效利用大规模脉冲网络的表征能力

3. **思考监督的边际效应**: 思考层监督在 depth=1 时没有带来提升 (30.00% vs 30.00%)，在 depth=2 时也没有改善 (22.50% vs 22.50%)。

4. **训练稳定性**: 所有实验的验证损失在 epoch 2-3 后均出现上升，表明存在过拟合。思考层监督并未缓解此问题。
